n 次方根与单位根

非零复数 z 恰有 n 个 n 次方根。它们都在半径为 |z|1/n 的圆上，相邻两根相差 2π/n，围成正 n 边形。拖动蓝点 z，或改变 n。

点击画布上的某个根（或右侧表格的一行）可以选中它，再按“验证 ωⁿ = z”。键盘：点一下画布，用方向键移动 z，按 + / − 改变 n。

输入 z

可以输入 1.5、√3、−5π/6、pi/4 等，按回车确认。
